# Evalúa Riesgos

**Evalúa Riesgos** is a high-performance Governance, Risk, and Compliance (GRC) platform designed to streamline risk management processes within organizations. Built with a modern tech stack, it provides a robust interface for identifying, assessing, and mitigating risks.

## 🚀 Key Features

- **Risk Management**: Centralized repository for identifying and tracking organizational risks.
- **Risk Assessment**: Tools for evaluating the impact and likelihood of risks using customizable criteria.
- **Control Implementation**: Define and monitor controls designed to mitigate risks.
- **Action Plans & Tracking**: Manage tasks and updates to ensure risk mitigation strategies are executed.
- **Organizational Hierarchy**: Structure risks and controls by departments, areas, or organizational units.
- **Indicators & Evidence**: Monitor Key Risk Indicators (KRIs) and maintain supporting evidence for audit trails.
- **Advanced Permissions**: Granular Role-Based Access Control (RBAC) using Filament Shield.

## 🛠️ Tech Stack

- **Framework**: [Laravel 12](https://laravel.com)
- **UI Framework**: [Filament v5](https://filamentphp.com) (Server-Driven UI)
- **Reactive Components**: [Livewire v4](https://livewire.laravel.com)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **Testing**: [Pest PHP](https://pestphp.com)

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Zequi22/Compliance_Riesgos.git
   cd app-evaluariesgos
   ```

2. **Run the setup command**:
   The project includes a convenient setup script:
   ```bash
   composer run setup
   ```
   *This command will install dependencies, set up the environment, generate keys, and run migrations.*

3. **Start the development server**:
   ```bash
   composer run dev
   ```
